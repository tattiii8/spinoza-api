# Spinoza API

Unauthenticated event bus for the Deleuze/Flaubert services.

## Important

Authentication and authorization are intentionally absent. Do not expose this service directly to an untrusted network. Put it behind a private network, firewall, VPN, reverse proxy, or service mesh.

## Run

```bash
docker compose up --build
```

API: `http://localhost:5004`
Swagger: `http://localhost:5004/swagger`

## MVP endpoints

- `POST /topics`
- `GET /topics`
- `GET /topics/{id}`
- `DELETE /topics/{id}`
- `POST /topics/{id}/subscriptions`
- `GET /topics/{id}/subscriptions`
- `DELETE /subscriptions/{id}`
- `POST /subscriptions/{id}/enable`
- `POST /subscriptions/{id}/disable`
- `POST /topics/{id}/publish`
- `GET /health`

## Event format

```json
{
  "type": "drive.object.created",
  "version": 1,
  "source": "flaubert-drive",
  "tenantId": "tenant-uuid",
  "subject": "object/uuid",
  "time": "2026-08-31T00:00:00Z",
  "data": {
    "objectId": "uuid",
    "name": "example.mp3"
  }
}
```

The event ID is generated by Spinoza.

## Delivery

Publishing persists the event and creates pending deliveries for matching active subscriptions. HTTP delivery is performed asynchronously with exponential backoff.

For production, add SSRF protection/endpoint allow-listing, maximum payload size, dead-letter handling, delivery signing, and graceful shutdown/drain.
